Fiche de suivi véhicules

Copie électronique d'une fiche papier. Scannez le code QR imprimé en haut de la fiche pour l'ouvrir.

Comment ça marche

Chaque fiche papier porte un numéro (GM-AA-NNNNN-C) et un code QR. Le code QR contient la clé de la fiche : sans lui, son contenu reste chiffré et illisible, même pour qui ouvre cette page.

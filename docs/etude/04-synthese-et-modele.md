# الجزء 4 — التركيب: من الدراسة إلى النموذج

---

## 1. ما الذي تعلّمناه من الأجزاء الثلاثة؟

| الدراسة | الدرس الجوهري | ما يعنيه للجزائر |
|---|---|---|
| **BTI / RTC** | اليقين القانوني المسبق في التصنيف ممكن ومجاني | الأداة **موجودة** في الجزائر منذ 2020 لكنها **شبه غير مستعملة** (< 100 قرار سنوياً) |
| **EUDR (+ CBAM)** | أوروبا تطلب "جواز بيانات" للمنتج، مدمجاً في التصريح الجمركي | المصدّر الجزائري يحتاج من يجهّز له هذه البيانات، **وخاصة CBAM** |
| **EUCDM / Data Hub** | البيانات تُدخل مرة واحدة وتخدم كل الإجراءات | الجزائر في مرحلة رقمنة الإجراء (ALCES)، والمرحلة التالية هي توحيد البيانات |

**الخيط المشترك:** القيمة لم تعد في "ملء التصريح"، بل في **"ملف بيانات سليم ومُتحقق منه قبل العملية"**.

## 3. المنتج: "ملف واحد، يقين كامل"

```
                    ┌─────────────────────────────┐
                    │   ملف الشحنة (Dossier)       │  ← مصدر الحقيقة الوحيد
                    │   مبني على WCO DM / EUCDM    │     (Once only)
                    └──────────────┬──────────────┘
          ┌──────────────┬────────┼─────────┬───────────────┐
          ▼              ▼        ▼         ▼               ▼
   ① التصنيف      ② قرارات    ③ التكلفة   ④ الامتثال     ⑤ التصريح
   اقتراح HS +    RTC/BTI     الرسوم      EUDR / CBAM /   (مسودة جاهزة
   درجة ثقة       السارية +   والضرائب    الوثائق /       للوكيل المعتمد)
   + مبررات       السوابق     النهائية    اكتمال الملف
```

## 4. النموذج المعلوماتي (Data Model)

### 4.1 الكيانات الرئيسية
| الكيان | الحقول الأساسية | مرجع EUCDM التقريبي |
|---|---|---|
| `Party` | الاسم، الدور (مستورد/مصدّر/مصرّح/ممثل)، NIF، رقم السجل التجاري، EORI (للأوروبي) | المجموعة 13 |
| `Dossier` | المرجع، الاتجاه (استيراد/تصدير)، بلد المنشأ والوجهة، Incoterm، العملة، سعر الصرف، النقل، التأمين، البنود، الوثائق | 11، 14، 16، 19 |
| `GoodsItem` | الوصف، رمز HS، الكمية، الوزن، القيمة، المنشأ، مرجع RTC | المجموعة 18 |
| `Document` | النوع (فاتورة، B/L، EUR.1، RTC، DDS…)، الرقم، التاريخ | المجموعة 12 |
| `Ruling` | الرقم، النوع (تصنيف/منشأ)، المصدر (DGD/EBTI)، الصاحب، الوصف، الرمز، السريان، الانتهاء | 12 (مرجع) |
| `TariffLine` | الرمز، الوصف، نسبة الحق الجمركي، نسبة TVA، DAPS، مؤشرات (ترخيص، منع) | — |
| `Finding` | النوع، الخطورة (مانع/تحذير/معلومة)، الرسالة، البند المعني | — |

### 4.2 قواعد العمل الأساسية (Business Rules)
| الرمز | القاعدة | الخطورة |
|---|---|---|
| R-RTC-01 | للمتعامل RTC ساري لهذه البضاعة، والرمز المصرّح مختلف | **مانع** |
| R-RTC-02 | RTC مذكور في البند لكنه منتهي الصلاحية | **مانع** |
| R-RTC-03 | RTC ينتهي خلال 30 يوماً | تحذير |
| R-CLS-01 | ثقة التصنيف < 60% | تحذير + توصية بطلب RTC |
| R-EUDR-01 | تصدير نحو الاتحاد + بند في نطاق EUDR + لا مرجع DDS ولا بيانات تحديد الموقع | **مانع** |
| R-CBAM-01 | تصدير نحو الاتحاد + بند في نطاق CBAM + لا بيانات انبعاثات | تحذير |
| R-DOC-01 | وثيقة إلزامية ناقصة (فاتورة، وثيقة نقل…) | **مانع** |
| R-VAL-01 | القيمة أو الوزن غير منطقيين (صفر، سالب، الصافي > القائم) | **مانع** |

### 4.3 حساب التكلفة (استيراد إلى الجزائر) — صيغة قابلة للضبط
```
القيمة لدى الجمارك (CIF بالدينار) = (FOB + النقل + التأمين) × سعر الصرف
الحق الجمركي (DD)               = القيمة × نسبة DD
DAPS (إن وُجد)                   = القيمة × نسبة DAPS
وعاء TVA                         = القيمة + DD + DAPS
TVA                              = وعاء TVA × نسبة TVA (19% أو 9%)
المجموع                          = DD + DAPS + TVA + رسوم أخرى قابلة للإعداد
```
> ⚠️ النسب في النموذج الأولي **توضيحية**. يجب ربطها بالتعريفة الرسمية وقانون المالية الساري قبل أي استعمال حقيقي.
